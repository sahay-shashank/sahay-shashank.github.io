Go Log is a lightweight logging framework built over Go’s existing logging mechanisms. 

The goal was not to replace Go’s logging, but to refine it.

---

## Core Ideas

- Wrap, don’t replace
- Keep performance predictable
- Make logs readable by humans and machines
- Encourage structured logging practices
