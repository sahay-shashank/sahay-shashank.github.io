**pkm** is a terminal-native personal knowledge manager inspired by the Zettelkasten method.
It enables the creation of small, interconnected notes stored securely on disk — fully encrypted, Git-friendly, and entirely under your control.

Think: *Obsidian-style linking + Git-native storage + strong cryptography — without leaving the terminal.*

---

## Why I Built It

I wanted a knowledge system that felt:

* **Local-first** — no cloud dependency
* **Secure by design** — encryption as a default, not an add-on
* **Composable** — small notes forming larger insight
* **Developer-native** — version control, filesystem clarity, CLI workflow

Most tools optimize for UI.
pkm optimizes for ownership, speed, and control.

---

## Core Capabilities

### Knowledge Engine

* Atomic note creation, editing, deletion
* Bi-directional linking between notes
* Tagging & categorization
* Full-text keyword search
* Tag-based filtering
* Encrypted indexing for fast retrieval

### Security Architecture

* AES-256-GCM authenticated encryption
* PBKDF2 key derivation (100k iterations)
* Per-user encryption keys
* Random salts & nonces
* Zero plaintext written to disk

Even in a public Git repository, the content remains unreadable.

---

## System Design

* Multi-user support with isolated encrypted stores
* Git-safe encrypted note files
* Clean filesystem hierarchy
* Designed for future distributed sync

Planned:

## Philosophy

pkm is built on a few core beliefs:

* Small notes create better thinking than long documents
* Links generate insight
* Local-first beats cloud-first
* If it’s your knowledge, you should own it
