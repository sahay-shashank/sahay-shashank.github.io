This UI Library is a lightweight collection of reusable React components built with **React**, **Vite**, and **CSS Modules**. It focuses on minimal structure, composability, and predictable behavior — without unnecessary abstraction or visual noise.

It isn’t just a side project — it powers this portfolio itself.

---

## Why I Built It

Most UI libraries have a lot of configurations tied up with the components.
I wanted one that prioritizes:

* Minimal surface area
* Clear internal logic
* Responsive-first layouts
* Styling isolation without global conflicts
* Fast builds and lightweight output

## Design Philosophy

Each component is:

* Focused on a single responsibility
* Built to be responsive by default
* Explicit in its API
* Free from hidden behavior
* Structured for long-term maintainability
