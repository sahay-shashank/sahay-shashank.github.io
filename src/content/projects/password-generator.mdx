A simple yet practical utility built in **Go**, designed to generate secure passwords through either a command-line interface or a minimal web endpoint.

---

## Why I Built It

I wanted a compact utility that:

* Works directly from the terminal
* Can also expose functionality via HTTP
* Has minimal dependencies
* Demonstrates clean Go structure
* Prioritizes predictable behavior

One binary. Two interfaces. Same core logic.

---

---

## Philosophy

The system is intentionally simple:

* Single responsibility core generator
* Shared logic between CLI and Web modes
* Clear separation of parsing and generation
* No unnecessary abstraction
